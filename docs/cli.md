## slopaudit scan

Scan code for LLM-app vulnerabilities, hallucinated imports and unfinished code.

```text
slopaudit scan [OPTIONS] [PATHS...]
```

| Option | Description | Default |
| --- | --- | --- |
| `--format`, `-f` | terminal, json, markdown or sarif. | `terminal` |
| `--output`, `-o` | Write the report here. |  |
| `--severity` | Minimum severity to report. |  |
| `--fail-on` | Exit 1 at this severity or above, or 'none' (default: high). |  |
| `--module`, `-m` | Run only these modules. |  |
| `--rule`, `-r` | Run only these rule IDs. |  |
| `--exclude` | Glob to skip (repeatable). |  |
| `--diff` | Scan only files changed against this git ref. |  |
| `--staged` | Scan only files staged for commit. | off |
| `--baseline` | Ignore findings recorded in this file. |  |
| `--write-baseline` | Record current findings as a baseline. |  |
| `--no-network` | Skip PyPI lookups. | off |
| `--config` | Path to a slopaudit.toml. |  |
| `--spec` | Check the code against this spec file. |  |
| `--llm` | Experimental: let the configured model judge --spec requirements. | off |

## slopaudit fix

Experimental: ask the configured model for fixes, re-scan, keep only real improvements.

By default this only prints a diff. Use --apply to write the files.

```text
slopaudit fix [OPTIONS] [PATHS...]
```

| Option | Description | Default |
| --- | --- | --- |
| `--max-rounds` | Stop after this many rounds. | `3` |
| `--min-severity` | Only repair findings at or above this. | `high` |
| `--apply` | Write accepted changes to disk. | off |
| `--yes` | Do not ask before writing with --apply. | off |
| `--no-network` |  | off |
| `--config` |  |  |

| Option | Description | Default |
